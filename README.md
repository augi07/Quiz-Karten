# Quit-Karten

Installation des node_modules bitte im Ordner Quiz-Karten. Um Node_modules zu installieren:

npm install

Anschliessend im Terminal auch:

npm run dev

mit http://localhost:9000 auf die Quiz-Karten Seite gehen
